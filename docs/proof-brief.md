# Product proof brief — Witness README

**Audience:** developers building multi-agent systems, agent infrastructure maintainers, technical founders, and teams that need accountable AI work.

**Claim:** Witness preserves decisions and outcomes as durable, identity-bound project context that another agent can retrieve after the original conversation is gone.

**Observable proof:** run the public MCP server locally, write one project decision and one outcome with a signed synthetic agent identity, then retrieve both from persisted project context.

**Source truth:** real Witness v0.1.0 public-core behavior and contract. No cloud service, customer metrics, or automatic Mission bridge is claimed.

**Destination:** GitHub README as product landing page; source-checkout terminal demo as primary proof; Mermaid sequence as supporting explanation.

**Evidence class: real.** The terminal demonstration executes the actual server, identity envelope, MCP calls, SQLite persistence, and bounded context read. Credentials and data are synthetic.

**Desired action:** understand the problem in under one screen, run the demo, then inspect the contract or roadmap.

**Constraints:** no invented integrations, users, savings, scale, semantic search, Spindle behavior, deployment, or SaaS capabilities. Dream functions must be labeled as enabled patterns rather than shipped orchestration.
